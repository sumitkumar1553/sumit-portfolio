# Sumit Data Analytics Portfolio

A personal frontend portfolio website built using HTML, CSS, and JavaScript.

This portfolio showcases my projects, certificates, resume, technical skills, and contact information in a clean, responsive, and professional design.

---

## Project Overview

Hi, I'm **Sumit Kumar**, an aspiring Data Analyst and Frontend Developer passionate about building clean, responsive, and user-friendly web applications.

This portfolio website was created to showcase my frontend development skills, projects, certificates, and resume in a professional way. I designed and developed the complete website using only HTML, CSS, and JavaScript while focusing on responsive design, clean UI structure, and smooth user experience.

The portfolio includes multiple sections such as:

- Home Page
- About Section
- Projects Showcase
- Certificates Section
- Resume Preview
- Contact Page

This project was built completely from scratch without using any frontend framework.

I built this project to improve my frontend development skills and create a strong online portfolio for internships and job opportunities.


Open the `index.html` file in your browser.
